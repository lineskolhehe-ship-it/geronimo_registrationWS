StudentRegistration project
============================

Files:
- index.html: form structure
- style.css: responsive styling
- script.js: validation and interactions

How to run:
1. Extract StudentRegistration.zip.
2. Open index.html in Chrome, Firefox, or another modern browser.
3. Try submitting the empty form to see field-specific errors.
4. Correct the errors and submit again to see the success message.
5. Use Show passwords and Reset Form to test those features.

Phone format: 11 digits beginning with 09 (example: 09123456789).
Password requirement: at least 8 characters.
Note: This is a front-end demonstration. It does not store or send student data to a server.
